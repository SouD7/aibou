# レビュー修正計画（2026-09-13）

1. ネットワーク64bit統計、IF変更時の差分、時計基準、ディスクエラー欠損を回帰テストで固定して修正。
2. ストレージ進捗は件数・合計と限定したエラー概要だけ通知する。全件配列は完了・中断時に一度公開し、閲覧用の親子索引をバックグラウンドで構築。走査件数とメタデータ量に明示的な上限を設け、上限時は中断・不完全を表示。保存結果はバックグラウンドで復元する。
3. 追加コマンドは予約時に操作IDを発行。開始前キャンセルと終了済み状態を実行前に検査する。
4. 履歴は個別欠測ごとに描画区間を分割。読み込み検証と普段の期限切れ処理を分離して全件辞書filterの反復をなくす。
5. 数値画面から独立した観測値の取得インターフェースを整える。既存画面の意味・単位・欠損状態は維持する。
6. 全テスト、最適化ビルド、合成大規模索引・24時間履歴の負荷、実機収集を確認。独立レビューを再実施し修正結果を記録する。

既存の外部送信・ファイル削除・自動修復なしの方針、通常2秒/詳細1秒、単発追加計測を維持。新たな外部ライブラリは追加しない。
