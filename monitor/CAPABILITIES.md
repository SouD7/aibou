# AIBOU Monitor：未対応項目と収集情報一覧

対象：`monitor/Sources/` の現行初期実装（2026-09-13の再レビュー修正を反映）。最初に提示された11分野の要望と照合した一覧。

「未対応」は現行実装の状態を指し、将来も技術的に不可能という意味ではない。取得処理があっても、すべてのMacで値を取得できるわけではない。実機検証済み環境はApple M1 MacBook Air / macOS 26.6.2。

## 1. 要望のうち未実装・一部対応のもの

| 元の項目 | 未対応・不足している内容 | 現在の対応と制約 |
|---|---|---|
| 1① ストレージ | 全ファイルの完全な列挙・継続追跡 | 読める範囲の手動スキャンと階層閲覧を実装。50万件・メタデータ見積もり128 MiB・エラー1万件で中断。完了・中断後に500件ずつ閲覧し、保存・復元ファイルは256 MiBまで。保護領域は欠損として表示。ファイルの変更を常時追跡する仕組みは未実装。外部・ネットワークドライブは明示選択時のみ対象。 |
| 1① ストレージ | 全ファイルを用途まで含めて自動分類 | ファイル・フォルダ・リンク等の種類、階層、パスに基づくタグまで。すべてのファイルの意味や用途を特定する分類は未実装。 |
| 1① ストレージ | macOS設定の「システムデータ」と一致するタグ | パスに基づく「システムデータ候補」を表示。Appleの内部分類と一致するものではない。 |
| 1① ストレージ | アプリ関連データの完全な一覧 | Bundle ID・アプリ名と標準保存先が一致する候補を列挙。任意の保存先や共有コンテナ等の完全な帰属追跡は未実装。 |
| 1① ストレージ | フォルダ削除によって実際に空く容量の厳密な算出 | 論理サイズと割当済みサイズを表示。APFSの共有ブロック・スナップショット等を含めた解放可能容量とは異なる。 |
| 2① CPU | 各コアが単位時間に処理したスレッド数 | コア別稼働率とプロセス別スレッド数を表示。スケジューラの実行履歴から「処理したスレッド数」を計測する機能は未実装。 |
| 2②③ CPU | 全プロセスの情報と総スレッド数の完全取得 | 取得できたプロセスを集計。取得できないプロセス数や部分取得を明示。親PIDとアプリ・OS等への帰属は別々に扱う。帰属には推定が含まれる。 |
| 3① GPU | プロセスごとのGPU占有率の連続監視 | 未対応。追加計測でGPU関連の元フィールドを表示できる場合はあるが、命令の追跡や統一した占有率への変換は行わない。 |
| 4① クロック | 動作周波数の安定した連続監視 | 通常監視では未取得。追加計測で周波数・P-state関連のフィールドが得られた場合のみ表示。管理者認証後の実機取得は未検証。 |
| 4① クロック | クロック回路のブレ・故障の診断 | 未対応。アプリの計測間隔のズレ、スリープ相当の時間差、壁時計との差を表示する。ハードウェアクロックの異常と断定しない。 |
| 5① メモリ | Activity Monitorと同一定義の「キャッシュファイル」量 | ファイルバックページ数に基づく量を表示。解放可能キャッシュ量やActivity Monitorの表示値と同一とはしていない。 |
| 5① メモリ | RAMとスワップを合わせたワイヤード量 | この合算は採用していない。ワイヤードはRAM内の領域として表示し、スワップ総量・使用量は別に表示する。 |
| 5② メモリ | プロセス別のワイヤード・非圧縮・圧縮・キャッシュの完全な内訳 | 未対応。常駐量と物理フットプリントを取得するが、これらを要求された内訳の代わりとして扱わない。 |
| 5③ メモリ | 「リークの可能性が高い」という診断 | 未対応。一定条件を満たす継続的なメモリ増加にタグを付ける。正常なキャッシュ増加等とリークの判別は行わない。 |
| 5④ メモリ | RAMの読み書き量・速度・レイテンシ | 全体・プロセス別とも未対応。ディスクI/O値をRAMアクセス量として代用しない。 |
| 6①② ファン・温度 | 全機種での最小・最大・現在RPM、CPU/GPU温度 | 条件付きのセンサー取得処理のみ。一部のIORegistryセンサー値が公開される場合に表示。検証したM1環境では取得できていない。 |
| 7② バッテリー | 電源入力の電力供給密度、VRM温度 | 未対応。バッテリー側の電圧・電流・算出電力、取得できる場合のアダプタ定格を表示。コンセント側の実入力電力や電力密度とは異なる。 |
| 8① ネットワーク | プロセス別通信量・速度の連続監視と長期累積 | 1秒区間の単発詳細計測。自動連続取得やプロセス起動以来の通信総量の追跡は未実装。全体パケット数の合計欄はなく、インターフェース別に表示。 |
| 8② ネットワーク | プロセス別の一般的な遅延・通信エラー診断 | TCP RTT・RTT変動・再送・接続状態の取得のみ。アプリの応答時間、HTTPエラー、全プロトコル共通の障害判定は未対応。 |
| 8③ ネットワーク | 接続先の常時・完全な追跡 | 単発計測時に見えた接続先を表示。計測の間に終了した短命接続等は捕捉できない。 |
| 9① ディスプレイ | EDID全項目の詳細な解析・表示 | 取得できる場合のEDIDバージョン・チェックサム概要まで。メーカーID・製品IDはCoreGraphicsから取得。 |
| 9② ディスプレイ | 実際の表示フレームレートの連続計測 | 未対応。解像度と設定リフレッシュレートを表示。設定Hzを実測FPSとして扱わない。可変・未申告のHzは欠損になる場合がある。 |
| 10① 外部I/O | 全接続方式の機器の網羅・即時認識 | USB・Thunderboltを30秒ごとに再列挙。Bluetooth等の全方式の一覧化や即時通知は未実装。 |
| 11 ハードウェア | 各部品の規格・型番の網羅 | Macモデル、CPU、RAM、OS、起動ボリューム容量、公開されたGPU識別情報まで。SSD・RAMチップ・VRM等の部品単位の詳細は未実装。 |

## 2. このモニタが収集・算出する情報

以下は取得処理が存在する項目の一覧。条件付きの項目は、機種・OS・権限によって値が得られない場合がある。画面の詳細表示や内部の照合に利用する情報も含む。

### 1. ストレージ

- ファイル・フォルダ名、パス、親フォルダとの関係、種類（通常ファイル・フォルダ・シンボリックリンク等）。
- ファイルの論理サイズ・割当済みサイズ、配下を集計したフォルダサイズ、走査全体の合計。
- シンボリックリンクの参照先。リンク先の再帰走査は行わない。
- スキャン開始・更新・完了時刻、進捗件数、読み取りエラーと対象パス、集計が完全かどうか。
- システムデータ候補タグと理由、重複実体・走査対象外タグと理由。
- アプリ本体と、Bundle ID・アプリ名由来の関連フォルダ候補、候補とした根拠。
- 関連候補の探索先：Application Support、Caches、Preferences、Saved Application State、Containers、HTTPStorages、WebKit等。ユーザーLibraryを中心に、一部は全ユーザー向けLibraryも照合。
- ディスクデバイスの累積読み込み・書き込みバイト数、差分速度、読み書きエラーの合計（未公開のカウンタは欠損・部分取得）。
- プロセスごとの累積ディスク読み込み・書き込みバイト数、差分速度、アプリ等への帰属。

### 2. CPU・プロセス

- 稼働可能な論理コア数、論理コアごとの稼働率。
- 全体のユーザー利用・システム利用・アイドルの割合。
- 取得できたプロセス数、取得できなかったプロセス数、取得できたスレッド数の合計。
- プロセス名、PID、親PID、起動日時、実行パス、取得できる場合のBundle ID。
- アプリ・OS・システム等への帰属。親PIDとは別の情報で、推定を含む。
- プロセス別CPU使用率とスレッド数。CPU使用率は1コアを使い切ると100%で、複数コア利用時は100%を超える。
- 差分計算用の累積CPU時間。PIDと起動日時を組み合わせ、PID再利用時の誤集計を避ける。

### 3. GPU（条件付き追加計測）

- `powermetrics` 出力のうちGPU関連のフィールド名、元の値、確認できる単位、取得時刻。
- 出力にプロセス情報が含まれる場合のプロセス名・PID。
- 現在のプロセス一覧と照合できた場合の親PID・帰属（推定）。
- 取得された追加フィールド数。GPU占有率の独自推計は行わない。

### 4. クロック

- 稼働中の計測間隔、スリープを含む計測間隔、その差から求めた停止・スリープ相当時間。
- 予定した計測間隔からのズレ（スケジュールジッター）。
- 壁時計の経過時間と単調時計の経過時間との差。
- 条件付き追加計測で、周波数・Hz・P-state関連のフィールド名、元の値、取得時刻。

### 5. メモリ

- 物理メモリ量。
- RAM占有量：物理RAMからfreeページ相当を引いた量。キャッシュも含む。
- ワイヤード量。
- 非圧縮占有量：RAM占有量からワイヤードと物理コンプレッサ領域を引いた量。
- 圧縮メモリが物理RAM内で占める量。圧縮前の相当量ではない。
- ファイルバックページの量。ほかのRAM分類と重なり得るため、独立した追加領域として合算しない。
- スワップ総量・使用量。
- プロセス別の常駐量、物理フットプリント、PID、親PID、帰属。
- 最大30分のフットプリント履歴から算出した増加傾向。10分以上観測し、64 MiB以上かつ20%以上増加し、75%以上の区間で非減少の場合に「メモリ増加が継続」と表示。

### 6. ファン・温度

- OSのサーマルプレッシャー：正常／やや高い／高い／重大。
- 対応センサーが値を公開する場合の現在・最小・最大ファンRPM、CPU温度、GPU温度。
- 条件付き追加計測で、熱・温度・ファン関連の元フィールド。

### 7. バッテリー

- 残量率、充電状態、取得できる場合の外部電源接続状態・推定残り時間。
- 単位を確認できる満充電容量（mAh）。
- バッテリー電圧（V）、電流（A）、電圧×電流から算出したバッテリー側電力（W）。
- 取得できる場合の電源アダプタ定格（W）。
- 保存を有効にしている場合、残量等の直近24時間の集計履歴。

### 8. ネットワーク

- インターフェース名と、各インターフェースの累積送受信バイト数・パケット数、送受信速度、入出力エラー合計。
- 物理集計への採用・除外の区分。
- UP状態の `en＋数字` を対象にした累積送受信バイト数と速度の合計。VPN・loopback等との重複を避けるための集計規則であり、全インターフェースの単純合算ではない。
- 単発詳細計測：プロセス・接続別の1秒区間の送受信バイト数、送受信速度、出力に含まれる送受信パケット数。
- 単発詳細計測：プロセス名・PID・帰属候補、ローカル／リモートの接続アドレス・ポート等の接続表示、TCP RTT、RTT変動、TCP再送、接続状態。列の有無と値は `nettop` 出力に依存。

### 9. ディスプレイ

- 接続画面数と画面識別子。
- 画素解像度、論理解像度（ポイント）、設定リフレッシュレート（Hz）。
- 画面の物理幅（mm）、ベンダーID、製品ID、内蔵画面かどうか。
- 取得できる場合のEDID概要（バージョン、チェックサム検証）。

### 10. 外部接続I/O

- USB・Thunderboltの機器名、接続方式、取得できるメーカー名・接続位置情報。
- 前回一覧との差から検出する接続・切断イベントと検出時刻。直近30件を起動中に保持。
- シリアル番号は収集しない。

### 11. ハードウェア情報

- Macモデル識別子、CPUアーキテクチャ、CPU名称。
- 物理メモリ量、論理CPU数、稼働可能CPU数。
- macOSバージョン、起動ボリューム容量。
- 取得できるGPU／アクセラレータ識別情報。必ずしも市販製品の正式な型番とは限らない。

## 3. 更新頻度・保存範囲

| 対象 | 更新・保持方法 |
|---|---|
| 基本監視 | 通常2秒、詳細1秒。計測負荷等で実際の間隔が変動するため、速度は経過時間を使って算出。 |
| ストレージ階層 | 手動スキャン。直近の完了結果をローカル保存。これは取得できた範囲の完了であり、全ファイルを読み取れた保証ではない。 |
| 外部機器・ハードウェア一覧 | 30秒ごとに再取得。 |
| プロセス別通信・接続先 | ボタン操作で1秒区間を単発計測。再計測まで最終結果を表示。 |
| GPU・周波数・熱の追加情報 | `powermetrics` の単発計測。通常権限での取得試行に加え、明示操作で管理者認証を利用可能。認証後の実機取得は未検証。 |
| 全体集計の履歴 | 許可した数値項目のみ10秒間隔、最大24時間を端末内に保存。保存の停止・削除が可能。全取得項目を保存するわけではない。 |
| プロセス別履歴・通信先 | 永続保存しない。メモリ増加判定用履歴は最大30分。通信詳細は起動中の最新結果を保持。 |
| 共通の付帯情報 | 取得元、単位、取得時刻、実測・算出・推定・部分取得・権限不足・非対応等の状態、必要に応じた計測区間と理由。 |

アプリを閉じると監視を終了する。収集情報を外部サーバーへ送信する機能はない。

## 取得失敗・部分取得の補足（再レビュー修正）

ディスクはIORegistry entryごとの差分を計算し、取得集合が変わった区間の偽速度を避けます。プロセス列挙失敗は実測0件として扱いません。観測APIでもCPU・I/O速度の実計測区間を保持します。機器一覧の不完全なサンプルから接続・切断を判定せず、バッテリーは内蔵電池の種別だけを選択します。powermetricsは解析上限で打ち切ったことを部分取得として表示します。
