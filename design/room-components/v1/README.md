# AIBOU — 部屋コンポーネント v1

部屋デザイン v2 とアバター Concept 01 / 01B を参照した、黒基調・白基調の9種類、計18枚の静止デザイン画像。内蔵 image_gen で生成。黒版を作成後、それぞれを編集対象として白版を生成し、構図・形をできるだけ揃えた。

[index.html](index.html) で黒白比較、各PNGで原寸確認ができる。最終生成指示と出力元は [prompts.json](prompts.json)、初期の制作指示は [brief.json](brief.json) に保存。

## 納品範囲

これらは不透明グレー背景のコンセプトPNG。透過スプライト、寸法を持つ3Dモデル、実際に動くUIコンポーネントではない。画像内の照明・時計・球の点灯は静止状態。初期生成で入ったチェック柄背景は修正済み。既存の部屋画像・アプリコードは変更していない。

## 共通の造形

黒はグラファイトの金属・チャコールの布、白は白いセラミック調の外装・銀の金具・淡いグレーの布地。シアン・アイスブルーを主光、ラベンダーを副光にする。部屋と共通する面取り、隠し配線、ボルト、回路の細線を使い、アバターの生活空間として家具の使いやすい形を残す。

画像ごとにキャンバス比率・描画スケールが異なるため、画像のピクセル寸法を実寸比として扱わない。白黒間にも微細な金具・発光部の生成差がある。部屋の四方向へ正確に配置する際は、共通3Dモデルから各カメラで再描画する。

## 動き・状態の実装仕様案

以下は後続実装のためのデザイン仕様であり、PNG自体は動かない。

- CPU/GPU：球の消灯を0、点灯を1とする。球ごとに独立した疑似乱数状態を持たせ、40〜120ms間隔で状態更新。CPUは4区画、GPUは多数の球が並列に動く。負荷が高いほど点灯密度と変化頻度を増やす。全球の一斉明滅は避け、筐体の縁の光は一定に保つ。モーション低減時は低頻度の密度変化か静止表示にする。
- ベッド：バッテリー残量を5分割ゲージへ反映。充電時は順番に穏やかな光を流す。枕や寝具は光らせない。
- 本棚：使用容量に応じて本型カートリッジの占有率、読み書きに応じて背表紙の小ランプを変える。
- デスク：作業中データを机上の板、メモリ使用率を机縁のゲージへ反映。
- 電波塔：送信をシアン、受信をラベンダーの小さなパルスで示す。オフラインでは電波の弧を消す。
- 時計：アプリの実時刻に同期。描かれた針と秒数字はコンセプト用で、実装時には独立レイヤーにする。
- ファン：2台のローターを独立させる。回転速度を各ファンの状態に対応させ、枠とグリルは固定。
- モニタ：画面を差し替え可能な面として分離。背面端子→ケーブル→壁端子の接続を維持する。
- 外部接続：床ソケットのリングで接続状態を示す。ケーブルの外部側・床挿入側は別アンカーにする。

## 3D化・UI組み込み時の分離単位

筐体、発光材、可動部、影を分離。デスクとチェアは別オブジェクト、ファンは枠・グリル・ローターを2組、CPU/GPUは筐体と各球の発光状態、時計は枠・盤・3本の針・秒表示、ケーブル類は本体・経路・接続端子を独立させる。
