# AIBOU — 固定カメラ用 2D画面素材 v1

黒・白 × 俯瞰・水平の4シーン。画面はすべて **1672 × 941 px**、左上原点です。今回の範囲は画面素材の制作です。

## 確認入口

- `index.html`：4シーンの切替、家具の表示／非表示、クリック領域、アバター予約位置、動きの見本。
- `previews/all-scenes.jpg`：4画面一覧。実際のレイヤーから合成しています。
- `previews/*-motion.webp`：CPU/GPUのランダム点滅とファン回転の12フレーム見本。実測値との連動はありません。
- `scenes/<theme>-<view>/<theme>-<view>.ora`：背景＋家具11レイヤー入りの編集用OpenRaster。

## 素材構成

`scenes/<theme>-<view>/` に背景PNG、家具11枚のRGBA PNG、クリック判定用グレースケールマスク、合成見本、ORAがあります。

| id | 対象 | メタファー |
|---|---|---|
| bed | ベッド | バッテリー |
| bookshelf | 本棚 | ストレージ |
| desk / chair | デスク／チェア | メモリ |
| compute | 豆電球アレイ | CPU / GPU |
| network | ミニ電波塔 | ネットワーク I/O |
| clock | 時計 | システムクロック |
| fan-1 / fan-2 | ファン各1台 | 冷却ファン |
| display | モニタ＋壁へのケーブル | ディスプレイコントローラ |
| external | 外部ケーブル＋床ソケット | 外部接続 |

PNGには実際のalphaチャンネルがあります。チェック柄を画像に描き込んだ疑似透過ではありません。`previews/*-layers.jpg` のチェック柄は検品用の表示だけです。

本セットは**固定配置のシーン用レイヤー**です。脚の間や塔の内側など、一部に局所的な背景・陰影を含みます。座標変更や、家具の後ろを自由に歩くアバター向けの完全な独立切り抜きとは異なります。今後のアバターは中央の空き床へ置く構成です。

背景は今回の家具画面から空室を再生成しており、最初の部屋参考画像とはパネルや配線の細部が異なります。各視点も独立した2D画像なので、3Dモデルからの厳密な投影一致は保証していません。

## 表示順と操作領域

`manifest.json` が家具レイヤーの座標・寸法・描画順の正本です。HTMLのfile読み込み用に同じ内容を `manifest.js` に同梱しています。

1. 背景を描画。
2. 家具を `z` 昇順で `source-over` 合成。
3. 必要なエフェクトを対応家具に重ねる。
4. アバターを `avatarSlots` の位置へ追加。

家具画像は全キャンバスサイズで、全て `(x=0, y=0)` に配置します。個別にトリミングする場合は元のオフセットを保持してください。クリックは `hitPolygons` で候補を絞り、必要なら `hitMask` の画素で判定できます。ビューアのクリック表示は素材検品用です。

## アニメーション／差し替え素材

`effects/<theme>/<view>/` に184枚のRGBA PNGを収録しています。参照・座標・中心・再生間隔は `effects/manifest.json` にあります。このmanifestの画像パスは **effectsディレクトリ基準**です。

- **モニタ**：画面内部、無地画面を分離。`display.quad` は左上→右上→右下→左下。無地画面に重ね、将来のバックエンド表示をこの四辺形へ写像できます。
- **バッテリー**：ヘッドボードの表示領域を分離。
- **CPU/GPU**：消灯・点灯素材と、12枚のランダム点滅連番。消灯を0、点灯を1として表現。1枚100ms。実行時に無限のランダム列を作る処理は含みません。
- **ファン**：各12枚の回転連番。筐体を残し、楕円内の羽根を置き換えます。中心ハブを固定。
- **時計**：文字盤、針を消した文字盤、合成針、独立した時針・分針。将来のシステム時刻への同期用に中心座標も収録。

連番は当該領域を置き換える透過オーバーレイで、全画面フレームのアニメーション動画ではありません。静止家具には元の発光・針・羽根が描かれているため、必要な消灯／無地／針なし面を先に重ねてから使用してください。動きの見本ではCPU/GPUとファンだけを再生します。

豆電球の数・配置は原画と露出の差で黒白間に差があります。ファンの回転は楕円に正規化した2D画像の変形です。時計の針を消した部分には小さな補間跡が残る場合があります。

## 今回含まないもの

アバターの状態別素材、アプリ本体、ネイティブUI、バックエンド連携、3Dモデルは含みません。アバターは配置予約位置のみです。モニタのグラフィックや点滅はデザイン見本で、PCの実測値ではありません。

## 制作・再現

画像生成で構図と絵柄を制作し、ユーザーの許可を受けてPython・Segment Anything・OpenCV・Pillowで輪郭抽出、透過処理、部品分離、連番化を行いました。ゲームエンジンのインストールは今回の素材制作には不要でした。

- `sources/`：家具入り生成原画
- `background-candidates/`：選定済みの空室原画
- `prompts.json`：画像生成指示
- `*-annotations.json`：抽出・エフェクトの座標
- `layers/`：SAMによる中間抽出（制作フォルダ内のみ。ZIPには含めません）。実際に使用する納品画像は **scenes/** と **effects/**
- `scripts/extract_layers.py`：SAM抽出
- `scripts/package_scenes.py`：配置用レイヤー、マスク、ORA、manifest
- `scripts/export_effects.py`：発光・回転・表示面・時計部品
- `scripts/export_previews.py`：実レイヤーから検品画像を出力
- `validation.json`：納品ファイルの検証結果

SAMは [Meta公式リポジトリ](https://github.com/facebookresearch/segment-anything) のvit_bモデルをローカル実行しました。重みは納品ZIPには含めていません。制作環境は一時仮想環境 `/private/tmp/aibou-mask-env`。Pillow / NumPy / OpenCV、再抽出時はPyTorch / torchvision / segment_anything とSAM重みが必要です。既存monitorアプリの依存関係は変更していません。

ブラウザ自動検品はローカルfile URLがツールのURLポリシーで拒否されたため未実施です。PNGの実視認、RGBA・座標・参照・合成結果・連番の内容、およびHTML内JavaScriptの構文を別途検証しています。
