# AIBOU — 固定カメラ用2D画面素材 v2

水平視点のCPU/GPUを**中央寄り・手前**へ移し、発光面を15%拡大しました。黒・白の両テーマに同じ変換を適用しています。俯瞰画像の配置はv1から変更していません。

優先順位は **各コンポーネントの見やすさ → 状態ごとのアバター配置**です。中央に立ち姿用の大きな空き領域を確保するルールを撤廃しました。ベッドの寝姿と椅子の座り姿を仮の配置先として `avatarSlots` に記録しています。

## 確認するファイル

- `index.html`：テーマ／視点切替、家具表示切替、クリック領域、アバター配置先、動きの見本。
- `previews/*-motion.webp`：点滅・ファン回転の12フレーム見本。
- `previews/all-scenes.jpg`：4画面一覧。納品レイヤーから再合成しています。
- `scenes/<theme>-<view>/`：背景、家具11枚、クリックマスク、合成PNG、編集用ORA。
- `effects/`：モニタ表示面・無地画面、バッテリー表示、CPU/GPU点滅、ファン回転、時計文字盤・独立針。
- `manifest.json`：家具レイヤー・操作領域・仮のアバター配置先。
- `effects/manifest.json`：エフェクトの参照・位置・中心・再生間隔。画像パスはeffectsディレクトリ基準。
- `layout-revision.json`：CPU/GPUの座標変換と今回の配置方針。
- `validation.json`：検証結果。

## 変更内容

水平画像で、CPU/GPUの中心を左へ340px、下へ125px移動し、中心基準で1.15倍に拡大しています。キャンバスは1672×941px。移動先で点滅が重なるよう、静止画・消灯・点灯・12連番・発光点座標・クリック領域・ORAを更新しました。

元のCPU/GPUに隠れていた電波塔の台座は、imagegenで局所補修して独立レイヤーへ戻しました。移動先のCPU/GPUには接地影を加えています。

4シーン合計で家具RGBA PNG44枚、エフェクトRGBA PNG184枚、編集用ORA4点。CPU/GPUの移動・拡大はPythonで既存素材を変換し、元の発光パターンを引き継ぎました。

## アバターと描画順

寝姿・座り姿は**位置案のみ**です。新しいアバター画像は含みません。中央常駐は前提にしていません。

`avatarSlots` の位置と大きさは、実際のアバターのポーズ素材を合わせる前の仮値です。寝姿では布団・ベッド手前枠、座り姿では肘掛け・机の前後関係に応じた遮蔽レイヤーが別途必要です。現在の家具には局所背景・陰影を含むため、任意のポーズをそのまま重ねれば完成する素材ではありません。

レイヤーは全キャンバスサイズで `(0,0)` に配置し、`z` 昇順で `source-over` 合成します。水平のCPU/GPUは手前の家具として `z=45`。クリックは `hitPolygons` と `hitMask` を使用できます。

点滅連番は1枚100msで、0を消灯、1を点灯として表現します。ファンも12フレームの2D変形です。時計・モニタは後で実際の情報を描くための面と部品です。実測値との連携、ネイティブアプリ実装は含みません。

## 再生成

`v1` は保持しています。v2の再生成には隣の `../v1` ディレクトリが必要です。

1. `scripts/revise_layout.py`：v1と `repairs/*-network.png` からv2のレイヤー・座標・ORAを再生成。
2. `scripts/export_previews.py`：合成結果と点滅見本を再生成。
3. `scripts/validate_assets.py`：RGBA、参照、再合成、連番、ORAを検証。

必要ライブラリはPillow、NumPy、OpenCV。`repairs/` にはimagegenの補修原画、抽出済み台座付き電波塔、[使用プロンプト](repairs/prompt.json)を保存しています。補修原画からの再抽出は `scripts/extract_tower_repair.py`（PyTorch・Segment Anything・vit_b重みが必要）です。

元原画は `sources/`、新配置での検証用原画は `sources/*-layout-v2.png`。以後の再配置はv2のmanifestとlayout-revisionを正本にしてください。元原画の座標と混同しないでください。

ブラウザ自動検品は以前ローカルfile URLがツールのポリシーで拒否されたため未実施です。画像の視認と、透過・座標整合・再合成・連番差分を検証しています。
