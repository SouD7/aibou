# AIBOU 固定カメラ用2D画面素材 v3

黒・白 × 俯瞰・水平、4画面の素材です。1672×941px、RGBA PNG、編集用OpenRaster（ORA）、クリック領域、アニメーション連番を収録しています。

## 今回の変更

- **ファン**：筐体・内枠、グリル、中心軸を固定し、羽だけを透過素材として分離。各基12フレーム。合成順は `fixedHousing → bladeFrames[n] → fixedGrille → fixedHub`。毎フレーム固定筐体から再描画して、前の羽を残さないでください。
- **CPU/GPU**：大きめの筐体を右壁の手前側に寄せ、部屋側に向いた金属面に脳の刻印を追加。両視点でデザインを更新し、発光面の消灯ベースと12枚の点滅連番も再制作。
- **配線**：部屋の回路線を消灯ベースに変更。シアン・青・ラベンダーの有限長の光が、線に沿って間隔を空けて流れます。24枚、1枚100msの見本です。家具のインジケーター、画面、電球は独立した発光部です。

## 確認するファイル

- `previews/fan-blades-motion.webp`：羽だけが回るファンの拡大見本。
- `previews/*-motion.webp`：配線の流光・CPU点滅・羽の回転を合成した2.4秒のループ。
- `previews/*-active.png`：動作中の1フレーム。
- `previews/all-scenes.jpg`：4画面の静止素材一覧。
- `index.html`：レイヤー表示、家具クリック領域、視点・テーマ切替、動きの見本を確認するローカルビューア。
- `scenes/<scene>/`：消灯配線の背景、家具11点の静止PNG、クリックマスク、合成画像、ORA。
- `effects/`：独立したファン部品、CPU連番、配線連番、既存モニタ・バッテリー・時計部品。
- `manifest.json`：家具の配置・描画順・クリック領域。ファンの `parts` は部品の参照。
- `effects/manifest.json`：効果素材の参照と再生順。画像パスは原則 `effects/` を基準に解決します。`source` はパッケージルート基準です。
- `validation.json`：画像・座標・合成・連番・ORAの検証結果。

## 合成の契約

全レイヤーはキャンバスと同じ大きさで、原点 `(0,0)` に `source-over` で重ねます。

1. `scene.background`：すでに配線の消灯処理を適用済み。
2. `effects.scene.wiring.frames[n]`：背景の上、家具の下。
3. 家具を `z` 昇順で描画。CPUは本体の直後に `compute.frames[n % 12]`、ファンは前述の4部品を描画。
4. 外部ケーブルをCPUの前に描画。

配線の `offBase` は全配線を消灯させた不透明の背景置換画像です。v3の背景に二重適用する必要はありません。通常の `scene.layers[].file` は静止表示用の合成済みファンです。動画では合成済みファンの上に羽を蓄積せず、部品構成に置き換えてください。

ORAではファンを固定筐体・羽・固定グリル・固定軸に分けて保存しています。配線アニメーション連番は `effects/wiring/` にあります。

## 範囲と制限

これは画面素材の制作です。ネイティブアプリ、OS計測連携、実時間時計、アバターの新規ポーズは含みません。アバターの寝姿・座り姿の仮アンカーを引き継いでいます。

家具は固定配置を前提にしたレイヤーです。局所背景・陰影や、他部品に隠れる面の補修を含みます。任意移動やアバターの背後歩行には追加の遮蔽・隠れ面制作が必要です。

ブラウザでの実動作検品は、以前ローカルURLがツールのポリシーで拒否されたため未実施です。静止画・連番の目視、PNGのアルファ、描画順、参照、再合成、ファン固定部の不変性を検証します。

## 再生成

`v1`・`v2` を保持しています。再生成スクリプトは隣接する旧版を参照します。通常の素材利用には旧版は不要です。

1. `scripts/build_cpu.py`：補修原画からCPU・外部ケーブルを分離。PyTorch / Segment Anything vit_bと重みが必要。
2. `scripts/build_compute_effects.py`：発光面の消灯・点滅を再生成。
3. `scripts/build_fans.py`：固定部と羽の分離素材を再生成。
4. `scripts/build_wiring.py`：消灯背景原画に経路と流光を再生成。
   `scripts/refine_network_alpha.py`：電波塔の背景を除いて透過を再調整。
5. `scripts/integrate_v3.py`：上記とv2を統合、manifest・背景・クリックマスク・ORAを書き出し。
6. `scripts/export_previews.py`：静止・動作プレビューを書き出し。
7. `scripts/validate_assets.py`：納品構成を検証。

主な画像処理依存はPillow、NumPy、OpenCV。CPU原画と消灯背景は組み込みimagegenで制作し `repairs/` に保存しています。
