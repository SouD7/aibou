# AIBOU — スケルトンPCの中の部屋 / 空間デザイン v1

白基調と黒基調、各5視点、計10枚の静止画コンセプト。内蔵 image_gen.imagegen で生成。全画像1672 × 941 px。`index.html` で色と視点を切り替えて比較できる。生成プロンプトは `prompts.json`、元画像との対応は `manifest.json` に保存。

## 空間の方針

ガラス張りの自作PCケースを、人が過ごせる広い一部屋に拡大した空間。白・黒のテックウェアとシアン／ラベンダーを持つ添付アバターに合わせ、サテン金属・薄いガラス・柔らかな陰影でまとめた。基板の回路は外周を密に、中央を疎にして、アバターの移動と家具配置の余白を取る。

- 北：大きな横長のメンテナンスパネルと、北西側の小さな丸い取付カバー2つ。
- 西：縦長のメンテナンスパネル3つ、端部の放熱フィンを思わせる縦リブ。
- 南・東：クリアガラス。南の東寄りにアクセスパネルを想定。
- 床：フラットなマザーボード。45度・90度で曲がる細い配線群、円形ビア、フラットな接点。
- 天井：ガラスと外周フレーム。俯瞰では天井と手前ガラスを非表示／薄くして視界を確保。
- 発光：シアン・アイスブルー中心、ラベンダー・マゼンタ、少量のミント。現段階は静止発光のみ。

## 後から置く別コンポーネント

アバター、ベッド（バッテリー）、本棚（ストレージ）、デスクとチェア（メモリ）、CPU/GPUを表すオブジェクト、電波塔のミニチュア（ネットワークI/O）、時計（システムクロック）、ファン2台、モニタと壁の外へ伸びるケーブル、外から床へ刺さるケーブルは、今回の画像には配置していない。丸い取付カバーは空間側の仮ディテールであり、ファン本体ではない。大きな横長パネルもモニタやCPUを確定したものではない。

## 3D化に向けた暫定寸法とレイヤー

以下は生成指示に用いた設計目安で、画像から計測した確定寸法ではない。

- 内寸：約9m × 9m、高さ3.5m。身長1.6mのアバターを基準。実装時は添付俯瞰のような相対サイズに調整。
- 水平カメラ：高さ1.55m、各隅から少し内側、水平画角80〜90度程度。垂直線を保つ。
- 俯瞰：南東方向から約35度の俯角。3D実装では正投影または弱い遠近感に統一。
- 座標案：床中央原点、X東、Y上、Z南。水平カメラのXZは南東(+4,+4)、南西(-4,+4)、北西(-4,-4)、北東(+4,-4)。注視点は中央の同じ高さ。
- レイヤー案：筐体／床・壁／ガラス／回路の溝／回路発光／取付ポイント／動的コンポーネント／アバター。
- 将来の発光アニメーション：回路ごとのパスに沿って光の帯が走る方式を想定。今回のPNGは発光を含む一枚絵で、レイヤー分離データ・アニメーション・3Dモデルは含まない。

## 確認と実装時の調整点

10枚の画像を目視確認し、壁／ガラスの組合せ、白黒の対になる構図、広い空床、後置きコンポーネントを含まないことを確認した。主要な壁構成は共通だが、画像生成による視点変更のため回路の細かな経路、ビア、ガラスの継ぎ目やアクセス部、金具、天井の反射には視点間の差がある。同一3Dモデルの厳密な5方向レンダーではない。実装用の位置合わせは共通モデル上で確定し、全視点を再レンダーする。ガラス外は暫定の無地背景。黒い衣装のアバターの読みやすさは実際の配置後に最終調整する。
