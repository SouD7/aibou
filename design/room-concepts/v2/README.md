# AIBOU — 部屋の空間デザイン v2

白・黒それぞれ俯瞰1枚と水平4方向、計10枚。内蔵 image_gen.imagegen で生成。元画像と生成指示は `prompts.json` に記録。`index.html` で全画像を比較可能。

## 今回の修正

- 室内の床形状を縦横同寸の正方形に統一。設計目安は9m × 9m、高さ3.5m。
- 四面の壁と天井をすべて不透明に変更。ガラスや透ける面、窓は使用しない。
- 俯瞰では内部を確認するため、天井を外し、手前二面の壁を低い切断面として表示。実際の部屋には四面の高さのある壁と天井を設ける。
- 水平では室内の四隅から対角を見る構図。床の発光回路、アバターと家具のための広い余白、白／黒の素材感を継承。

| 番号 | 視点 | 左／右に見える面 |
| --- | --- | --- |
| 01 | 南東上空からの俯瞰 | 西壁／北壁、正方形の床全体 |
| 02 | 南東 → 北西 | 西壁／北壁 |
| 03 | 南西 → 北東 | 北壁／東壁 |
| 04 | 北西 → 南東 | 東壁／南壁 |
| 05 | 北東 → 南西 | 南壁／西壁 |

床・壁の回路はシアン、アイスブルー、ラベンダー、マゼンタを中心とした静止発光。天井はマットな不透明パネルと外周の細い照明。アバター、ベッド、本棚、デスク・チェア、CPU/GPU、電波塔、時計、ファン2台、モニタとケーブル、外部接続ケーブルは後置きの別コンポーネントとして扱い、画像には含めない。

## 確認範囲

10枚を目視し、透明な壁・天井がないこと、俯瞰の床が対称な正方形の投影として見えること、白黒の対応する画角を確認。PNGは各1672 × 941 px。これらは画像のデザイン案であり、寸法を持つ3Dモデルではない。視点間で回路、天井の細線、金具、扉の位置・形に生成上の差が残る。正方形の寸法および厳密な位置合わせは3D化時に共通モデルで確定する。今回の更新は v2 に保存し、v1 は保持。
