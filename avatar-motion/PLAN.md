# SpriteKit animation prototype

Use the selected original Concept 01 avatar (black bob, graphite/ivory hooded jacket, shorts and opaque tights) in the user-supplied white cyber room. Create a separate native prototype so the animation can be reviewed at room scale and close up.

- Author separate transparent standing, reclining and rear-reading pose artwork from approved references.
- Drive localized SpriteKit grid deformation: stable foot/bed contact, slow weight shift, delayed hair/sleeve motion, breathing. Add irregular eyelid closure and audio-amplitude lip sync for standing only.
- Match the sleeping pose to the left bed and the reading book to the black/cyan books in the shelf. Keep sleeping eyes closed.
- Provide pose controls, motion strength, pause/reduced motion, close-up view, sample voice and local audio input.
- Bundle source art, manifest, code and reproducible build. Verify compilation, pure motion behavior, native UI actions, rendered placement, frame differences and audio playback synchronization.

This iteration is a code-driven 2D deformation prototype, not a Cubism model or a full character skeletal rig. Original design sheets remain the appearance source; pose-specific occluded details are newly authored.
