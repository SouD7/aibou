# AIBOU 統合アプリ

AvatarMotionの部屋とアバターに、Monitorの実測データ・詳細画面・相談機能を接続したmacOSアプリです。既存2アプリのソースを直接共有し、新しい依存パッケージは追加していません。

作成に用いたソース・素材・設定・テスト・検証記録の全ファイル一覧は [FILE_INVENTORY.md](FILE_INVENTORY.md) に記録しています。

## 起動

ビルド済みの `integrated/AIBOU.app` もGitで管理しています。Apple SiliconのMac（macOS 13以降）では、このアプリを直接開けます。ソースから再ビルドする場合はXcode Command Line Toolsを用意し、以下を実行してください。

```bash
./integrated/run.sh
```

`integrated/AIBOU.app`をビルドし、全画面で起動します。ビルドのみは`./integrated/run.sh --build`、通常ウィンドウでの検証は`./integrated/run.sh --windowed`です。macOS 13以降、Xcode Command Line Toolsが必要です。

## 操作

- 起動時に添付素材のオープニング（24fps・2.25秒）を1回再生し、終了後は0.65秒で暗転し、短い黒画面を挟んで0.8秒で部屋画面をフェードインします。「スキップ」またはEscキーで省略できます。全画面切り替え後に再生を開始し、ウィンドウへ戻っただけでは再生し直しません。「視差効果を減らす」が有効なら最終フレームを短く静止表示します。

- 家具をクリックすると、説明・全体の負荷・「詳細を見る」が表示されます。詳細には既存Monitorの対応タブ全体を表示します。椅子もメモリに対応します。
- macOSメニューバーの「コンポーネント」からも家具を選べます。各項目に表示された `⌥⌘1`〜`⌥⌘0` で選択、`⌥⌘D`で詳細を開けます。メニューはキーボード・VoiceOverで操作でき、選択した家具は部屋内で強調されます。通常の部屋画面上部には選択ボックスを表示しません。
- 左上の「メニュー」で6つの円形ボタンを展開します（各84pt）。「タイトルへ」でオープニングの先頭から再生し直し、暗転・フェードインを経て部屋へ戻ります。相談中は相談表示を終了してからタイトルへ移ります。「メンテナンス」は状態チェックのみ、「アプリ」はアプリ一覧のみ、「モニター」はサイドバー付きの全機能を表示します。「学習」で展示館へ移動します。展示館上部の「ラボへ戻る」で部屋へ戻れます。同じ起動中は展示館の部屋・ゲームの入力状態とラボの家具選択を保持します。移動時には移動元の読み上げを停止します。
- 「デモ」は既存AvatarMotionの操作枠を表示します。実測値による表示更新と自動ポーズ変更を一時的に止め、手動操作を優先します。「デモを終了」で最新の実測状態と初期ポーズに戻ります。
- 左下の「相談」でChatGPT接続を確認し、接続済みなら下部に質問欄を表示します。未接続なら接続案内を表示します。既存Monitorと同じCodex CLI接続を使います。
- 相談は送信内容を確認してから送信します。回答後に「追加」で空白の質問欄を追加できます。質問と回答は下部から上に流れます。回答の長さは「モニター」→「相談」で設定します。
- 入力途中で相談を終了しても、同じ起動セッションで再開すると下書きの入力欄を復元します。送信内容の確認画面で終了した場合も入力欄へ戻り、送信前にもう一度確認します。
- 相談中にモニターを開いて質問を編集したり「新しい相談」に切り替えたりした場合も、部屋へ戻ると最新の内容で入力欄を復元します。パネルを開く前の送信確認は引き継がず、再度確認します。パネル表示によって相談の接続や回答処理を停止することはありません。
- 相談中の姿勢は「立つ（前で組む）」に固定され、「終了」で「立つ（後ろで組む）」に戻り、10秒周期を再開します。

## 学習の独立性

学習は `game-lab/` の検証済み単独版を `AIBOULearning` モジュールとして接続しています。ゲームのルール・素材・セーブ形式は変更していません。単独版は従来どおり `./game-lab/run.sh` で起動でき、その場合は「ラボへ戻る」を表示しません。統合版も学習の既存セーブ先を使います。

## 実測値と表示状態

| 部屋 | Monitorの指標 | 表示 |
| --- | --- | --- |
| 本棚／ストレージ | 起動データ領域の空き÷総容量 | 70%以上：スカスカ、10%以上70%未満：中くらい、10%未満：あふれる |
| CPU | アイドル率 | 50%以上：水色、10%以上50%未満：黄色、10%未満：赤色 |
| 時計 | 稼働中の計測間隔 | 指標表示のみ |
| デスク／メモリ | RAM占有量÷物理メモリ | 80%未満：通常、80%以上99%未満：書類の山、99%以上：あふれる |
| ファン | サーマルプレッシャー | 正常：ゆっくり、それ以外の観測済み状態：高速 |
| ベッド／バッテリー | 現在の残量 | 75%以上：4灯、50%以上：3灯、25%以上：2灯、1%以上：1灯、1%未満：0灯 |
| ネットワーク | 物理IF受信速度 | 水色（青系） |
| ディスプレイ | 接続画面数 | 通常 |
| 外部接続 | 外部機器一覧 | 指標表示のみ |

未取得・非対応・過去値・不正な値は0として判定せず、前回の表示状態を保持します。初回は既存の部屋の既定表示を使い、サマリーには取得状況を表示します。監視停止中は最後の観測値であることを表示します。

本棚／メモリのあふれ、CPU赤色、ファン高速、バッテリー1灯以下、ネットワーク赤色、ディスプレイ砂嵐で警告を表示します。警告マークをクリックすると、そのコンポーネントの警告は同じ起動セッションでは再表示しません。アプリを再起動すると解除履歴はリセットされます。2基のファンは1つの警告として解除します。

通常は9種類の姿勢から10秒ごとにランダム選択します。バッテリー1灯以下→眠る、本棚あふれ→読む、メモリあふれ→書く、CPU赤色→突っ伏す、ネットワーク赤色→ノイズの条件があれば、それらの候補だけから選択します。同じ姿勢の連続選択も許可します。ネットワーク赤色とディスプレイ砂嵐は実測時には選ばず、デモで確認できます。

統合版の監視履歴は`~/Library/Application Support/AIBOU`に保存し、既存Monitorの履歴と分離しています。相談の接続環境は既存のAIBOU専用Codex環境を共有します。

## 検証

```bash
./integrated/test.sh
./avatar-motion/test.sh
./monitor/test.sh
./integrated/run.sh --build
```

統合テストは閾値境界、欠測と不正値、警告、複数条件のアバター候補、10秒周期、相談・デモからの復帰、警告解除と再起動、別ウィンドウの通知による誤停止を検証します。相談は模擬RPCで追加質問・回答設定・切断と再接続を検証し、実際のOpenAIへの送信は行いません。ビルド時のSwift警告はエラー扱いです。
