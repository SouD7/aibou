# 部屋の電流アニメーション

1672×941 / 24fps / 96フレーム / 4秒のループ。
天井・壁・床の配線経路に沿って、シアン、濃青、紫、ピンク、金色の光が尾を引いて流れます。
位置は一定速度で進み、経路の端では滑らかに消えます。最終フレームの次に先頭フレームを再生します。

- Frames/frame-000.png ～ frame-095.png: 背景込みPNG。順に表示するだけで再生できます。
- LightFrames/light-000.png ～ light-095.png: 同じ光の透過PNG。background-base.pngの上に1枚ずつ重ね、さらにその上に家具を描画します。
- background-base.png: 固定発光を消した不透明な背景。
- sequence.json: 再生速度、順序、画像サイズ。
- preview.html: ブラウザーで開く再生確認画面。一時停止・コマ送り可能。
- contact-sheet.png: 6時点の確認画像。
- routes.json / render-current.cjs: 光の経路と再生成スクリプト。

背景は内蔵imagegenで元background.pngを編集（短い固定発光のみ消灯、明るさ・画角を維持、不透明背景を指定）。光はフレーム間で家具や背景が揺れないよう、コードで同一軌道の位置だけを進めてPNG出力しています。
画像の背景込み版と透過版は代替手段です。同時に使うと光が二重になるため片方を選択してください。
アプリ本体には未組み込み。動きを減らす設定ではframe-000.pngを静止表示してください。
