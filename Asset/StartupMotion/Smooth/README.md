# AIBOU 起動PNG連番

- 1672×941 px、54枚、24fps、2.25秒、ループなし
- frame-000.png → frame-053.png の順に表示
- sequence.json：サイズ、fps、再生順
- preview.html：ブラウザーで再生確認（再生ボタンでリプレイ）
- contact-sheet.png：代表6コマの一覧

同一のベクター定義から全コマを描画し、背景とロゴの形を固定。周囲の電流、端子の発光、Aの線の充電、丸の伸縮、ロゴの浮き上がり、文字の左からの点灯を時間で変化させています。最後は静止するため同じ画像のフレームもあります。

白い背景込みのPNGです。部屋への切り替えはアプリ側で行う想定で、この連番に部屋画像は含みません。アプリへの組み込みはまだ行っていません。

生成画像のデザインを参考に、連番向けにロゴと回路を描き直しています。元画像の画素をそのまま切り貼りしたものではありません。再書き出しスクリプトは ../render-smooth.cjs です。
