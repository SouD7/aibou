確認日：2026年9月15日。対象は `LessonExperienceView.swift`、`LessonActivityView.swift`、授業カタログ・進捗モデル、および展示館の授業入口。下記の作品については開発元・作者の一次資料を確認した。実際に各作品を通してプレイした比較検証ではない。

## 一連の利用体験

1. **話しかける。** ロビーの女の子にカーソルを合わせ、選択できることを示す。クリックで授業ノートを開く。上部の「授業」からも同じ場所に入れる。
2. **問いを選ぶ。** 5分野のタブから4授業ずつを表示する。授業名に加え「保存したのに、どうして机が空かないの？」などの問いを出す。履修順によるロックは設けない。
3. **見つける。** 女の子が身近な場面から説明し、ノート側で問い・短い原理・今回の到達目標を示す。
4. **試してみる。** ボタンで入力、順序、処理役、データ量などを変更し、同じ模型内で結果を見比べる。模型で省いた条件も示す。
5. **考える。** 条件を明示した3択に答える。数値や条件を変えて考える問題と、役割を確認する問題を組み合わせる。間違いには理由を返し、選び直せる。
6. **つなげる。** 発見を一文で整理し、ラボのどの表示とつながるかを案内する。授業の完了を記録し、関連展示・ラボ・別の授業へ進める。

「考える」の全問を、学習研究上の転移を測れるテストとは扱わない。現状は短い理解確認であり、数値条件を変える問題にも、同じ形式への慣れや消去法で正答できる可能性がある。

## 実装への対応

| 原則 | 現在の実装 |
|---|---|
| 展示館と同じ場所で教わる | 背景の部屋を淡く残し、左に女の子、右に紙色のリングノート。展示分野の差し色を見出しや操作へ使用。 |
| 一つずつ理解する | `LessonStep` の「見つける／試してみる／考える／つなげる」。各段階で説明と操作を切り替え、現在地と戻る操作を表示。 |
| 操作で因果を確認する | `LessonActivityView` の20種類の模型。たとえばメモリは保存と解放、キャッシュは初回と再要求、GPUは画素数と処理レーン、通信は帯域と遅延を比較する。 |
| 体験と確認を経て記録する | `LessonSession` は実験操作と正答がそろってから「つなげる」へ進む。授業を開いただけでは完了にならない。 |
| 誤答から戻れる | `correctFeedback` と `incorrectFeedback` を授業ごとに用意。三択を選び直し、前の実験にも戻れる。 |
| 身近な表示へ結びつける | `labConnection` でCPU・メモリ・保存・通信などの見方を説明。統合先が提供されている場合だけ「ラボへ」を表示する。 |
| 女の子が場面に反応する | 選択時は `welcome`、説明と実験・問いでは `explaining`、発見時は `celebrating` の静止差分へ切り替える。身体を揺らす演出は加えていない。 |
| 自分のペースで読む・聞く | 説明は常に文字で表示し、音声はスピーカーボタンを押したときだけ再生。段階変更、授業変更、閉じる操作で再生を止める。音声が利用できない理由も表示する。 |
| 学習と本編の記録を分ける | 授業完了は `lessons-v1.json`、本編の回路と作品は既存の記録を使用。「発見済み」は授業の進捗であり、本編ゲームを完成した印ではない。 |
| 根拠と模型の限界を確認できる | 全授業に出典のリンクと `analogyLimit` を用意。実験の見出しでも模型であり実測値ではないことを示す。 |

UIでいう「対話」は、事前に編集した台詞、選択、実験結果、確認問題への応答で構成する。自由入力に何でも答えるAIチャットや、理解度を自動診断する先生は今回の実装には含まれない。任意音声と短い台詞は、作業中にも利用できるAIBOUのための設計判断であり、参照作品が同じ仕様であるという意味ではない。

## 提供範囲と検証の限界

- **授業は20テーマすべてにある。** 各テーマに説明、操作模型、理解確認、実機との接続を用意する。
- **本編ミニゲームは既存の回路のみ。** ほか19テーマは関連展示へ移動でき、ゲーム準備中の表示を保つ。授業の実験は繰り返せる。
- **模型は実機の動作や性能の精密な再現ではない。** 定速、独立した仕事、損失なしなどの仮定を置く。圧縮の記号数はバイト数と別。スループットの模型と、一回の作業時間の問題も区別する。
- **一度ボタンを押した事実は、理解の証拠ではない。** 現在の実験到達条件は最低限の操作を促す仕組みであり、十分な比較や説明ができたかの評価ではない。
- **学習効果は未実証。** コードの整合性・正解の計算・画面操作の検証と、学習の定着や日常への応用の実証は別。次の評価では、条件を変えた口頭説明と、時間を置いた実機表示の読み取りを確認する。
- **この文書はコードと資料のレビュー記録。** 実際の表示サイズ、文字切れ、女の子の素材の品質、往復操作の確認結果は、統合側の画面検証記録を参照する。

これらの境界を明示することで、今回の完成範囲を「女の子から授業を選び、20の小さな実験を通して理解の入口を得る体験」として扱う。
