# 展示館の実装用原画

2026-09-14。内蔵 imagegen を使い、`output/exhibition-home-v3` の構図・絵柄・少女の各ポーズを保持して制作した。元の参照画像は変更していない。

## 納品

`game-lab/Art/Exhibition/` の `lobby.png`、`area-a.png`〜`area-e.png`、`circuit-entry.png`、`guide-notebook.png`。全生成プロンプトは `prompts.json`、生成元とファイル検証情報は `manifest.json`。

背景は約16:9（1672×941、Dのみ1671×941）。少女の作品帳イラストは1145×1374。実装時は背景と操作領域を同じ座標系でフィットさせる。

## 確認したこと

- ロビーに5つの扉、各室に4つの独立した展示を維持した。
- すべての背景から上部ナビ、説明文字、浮いたボタンを除去した。物理的な看板は空白で保持し、アプリ側で読みやすい文字と操作を重ねられる。
- 少女の黒いボブ、青い目、黒・白・シアンの服装を維持。ロビーは作品帳、Aは回路部品を提示、Bは着座、Cは収納、Dは接続、Eはしゃがんで冷却を観察するポーズ。
- D室の模型はCPU・RAM・SSD・GPU・画面を表す部品で保持。名称は原画から消してあり、必要ならネイティブ文字を追加する。
- B室では生成された点数に誤りが残ったため、その不採用版は `area-b-first.png` と `area-b-correction.png` に保存。採用版では4枚の算術カードをすべて空白にし、誤った足し算を描かないようにした。左の形状カードと右の並列レーンの形は保持した。
- 各生成結果を目視で確認。独立した指・髪・目・顔・展示の主要形状に明確な破綻がないことを確認した。UI動作検証は別途、アプリ実装側で行う。

## 少女イラストの取り込み

透過指定の初回生成はチェック模様が実画像に焼き込まれていた（`sips` にて `hasAlpha: no`）。不採用版 `guide-notebook-alpha-attempt.png` は原画の追跡用に残している。

採用した `guide-notebook.png` は imagegen で背景を純緑へ変更した画像。PNGのalphaはない。既存の `ImageProcessing.removeGreenScreen` を読み込み時に使う前提であり、そのまま背景へ重ねない。元の生成alphaがあるという扱いをしない。

頭部クロップ候補（左上原点の正規化rect）は `(0.16, 0.00, 0.60, 0.44)`、全身上半身は `(0.05, 0.00, 0.90, 1.00)`。顔中心はおよそ `(0.50, 0.29)`。これは実表示に合わせて調整する候補である。
